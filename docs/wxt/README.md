## 准备工作

在开始本教程之前，请确保您具备：
- 基础的 JavaScript/TypeScript 开发经验
- 了解浏览器扩展的基本概念
- 已安装 Node.js 18+ 和 pnpm/bun/npm 之一

> **提示**：建议使用 pnpm 或 bun 以获得最佳开发体验。
